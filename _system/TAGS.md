# Tag taxonomy

Use only these. To add a tag, add it here in the same commit.

- **type** (frontmatter `type`): main, side, soup-bowl, breakfast, dessert, sauce, prep-component, snack, cocktail, mocktail
- **protein**: chicken, turkey, beef, lamb, pork, fish, shellfish, egg, veg, organ
- **cuisine**: american, mexican, italian, japanese, chinese, korean, thai, vietnamese, indian, mediterranean, southern, fusion
- **method**: dutch-oven, air-fryer, grill, sheet-pan, one-pot, no-cook, braise, smoker, stovetop
- **effort**: quick-20, weeknight-30, weeknight-45, weekend-project, make-ahead, freezer-friendly, leftovers-friendly
  (Weeknight dinners are the priority: every main or bowl should get one time tag, quick-20 / weeknight-30 / weeknight-45 / weekend-project.)
- **occasion**: hosting, date-night, crowd, holiday, halloween
- **season**: spring, summer, fall, winter
- **diet**: high-protein, gluten-free, dairy-free
- **cocktail spirit**: bourbon, rye, gin, vodka, rum, tequila, mezcal, brandy, amaro, zero-proof
- **cocktail style**: stirred, shaken, built, batch, highball, sour
