# Shortcuts

- **Sync Groceries** (`make_sync_groceries.py`): adds this week's grocery list from https://blind-tiger.pages.dev/groceries.txt to the shared Apple Reminders list "Groceries", skipping anything already there (open, or checked off in the last week; whole title, any case) and anything it already added this week. Each title it adds is appended to `Shortcuts/Cookbook/groceries-sent-<YYYY-Www>.txt` in iCloud Drive, so deleting a reminder is safe: that item will not be added again until the next week. New lines on the grocery list still get added. The notification counts only reminders it actually added: "Added N: item, item" or "Nothing new to add". Install on iPhone from https://blind-tiger.pages.dev/sync-groceries.shortcut.
- To change it: edit the script, run `python3 _system/shortcuts/make_sync_groceries.py "Sync Groceries.shortcut"`, sign it on a Mac with `shortcuts sign --mode anyone --input "Sync Groceries.shortcut" --output "Sync Groceries signed.shortcut"`, and save the signed file as `_system/web/sync-groceries.shortcut`. iOS won't import an unsigned file.

- **Add Bought Groceries:** iOS cannot run a shortcut at the moment you check off a reminder. After shopping (or on a time-of-day / "Reminders app closed" automation), a shortcut reads completed items from the shared "Groceries" list and POSTs them to `/api/inventory` so they are added to `kitchen/inventory.md`. Build it on the iPhone; steps are in `_system/docs/INVENTORY.md`. Do not put an API key in this repo. Deleting a reminder is safe for Sync Groceries (it logs each title it adds for the week). Completed titles from the last week are still skipped too.
